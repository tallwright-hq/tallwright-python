# Contributing

Issues are welcome: a bug, a question the documentation did not answer, a platform the SDK does not
install on. Please say which version (`python -m pip show tallwright-cloud`), which Python, and what
`tallwright-cloud doctor` prints where your agent runs. Never paste content you recorded, a
`disclosure.json`, or a key.

Pull requests are not accepted yet. Each release is made from Tallwright's own repository and arrives
here as one commit, so a change made here would be overwritten by the next release. If you have a
fix, describe it in an issue and it will be taken up there.

A security problem goes to [SECURITY.md](SECURITY.md), not to an issue.
